# 叙剪 · 脚本剪辑工作台

本地运行的脚本驱动剪辑工具。Node.js 20+ 与 FFmpeg/ffprobe 为唯一运行依赖，无需 npm 安装。Windows 双击 `启动工具.cmd`，或在目录执行 `node server.mjs`，打开 http://127.0.0.1:4317。FFmpeg 须包含 libx264、AAC、subtitles/libass。服务仅监听本机。

## 使用
1. 在素材库导入视频及音频，并补充人物、场景、动作、景别标签。分段 JSON 可提供源入出点和已校对台词。
2. 输入或导入 TXT/JSON 分镜。每行格式：`镜号 | 场景 | 人物 | 动作 | 景别 | 时长秒 | 台词 | 必留 | 开场/过程/结果/收尾`。普通文本每行视为一镜。JSON 接受数组或 `{ "shots": [...] }`。
3. 解析匹配。默认保留脚本顺序，每镜列出最多五个备选和匹配依据；低分镜头标为缺镜。
4. 点击镜头调整素材、源入出点、字幕、声画偏移、原声音量、末帧停顿、基础调色和声音衔接。必留镜头不能被删除或跨越重排；可手动锁定其他镜头。
5. 回看和检查。按镜号或 `分:秒.小数` 定位。修改自动复查相邻镜头的已填服装、道具和动作方向。
6. 选择粗剪/精剪、横竖画幅、音乐和烧录字幕，导出 H.264/AAC MP4，同时生成逐镜 JSON 与 SRT。源片段顺序预览不含最终特效，混音、停顿与字幕以导出成片为准。

## 实现与范围
- 匹配使用文件名、人工/模型标签及已输入台词的文本检索，分数不是概率。不会在无依据时宣称理解人物身份或动作。
- 可选视觉模型：设置环境变量 `VISION_API_KEY`、`VISION_BASE_URL`（默认 OpenAI 兼容 `/v1` 地址）、`VISION_MODEL`。每次“模型分析”会向该服务发送六张带时间码的采样帧；消耗由服务商计费。密钥只从服务进程环境读取，不写入网页或项目。模型结果需人工复核。
- 尚无自动语音识别、方言校对、音素/口型追踪、动作事件检测或故事重写模型。精剪提高编码质量，并执行用户确认的剪辑参数；不能自动完成专业精剪判断。
- 叙事目标与阶段用于记录和人工组织，默认始终保留输入顺序。全/中/特写通过景别标签检索，不会凭文件本身推断。
- J-cut 将下一镜入点前 0.3 秒原声提前叠加，L-cut 将上一镜出点后 0.3 秒原声延后叠加；须存在音轨和源余量，否则该处保持硬切。声音偏移作用于本镜原声。当前未提供独立外录对白同步与多轨旁白编辑。
- 关键台词区间自动降低音乐，限幅控制峰值。根据输入台词区间压低，不是声学 VAD。基础调色提供暖色和清透两档，非镜头自动色彩匹配。
- 源片保持比例并加黑边，25fps，横版 1280×720，竖版 720×1280。粗剪 CRF23，精剪 CRF18；字幕烧录最终编码 CRF20。
- 字幕每镜一条，支持文本校对和 SRT 下载；更细的逐句时码需拆镜或外部编辑。
- 本机 `data/` 保存素材和渲染结果，浏览器 localStorage 保存项目；下载项目 JSON 以备份。跨电脑导入需重新导入并指派素材。
- 静态托管网页只能体验示例、脚本解析、时间轴编辑、JSON/SRT 下载。本机上传、模型和 MP4 渲染必须通过本地服务使用。

## 开发
`node --test tests.mjs` 执行核心检查。`node build.mjs` 生成静态网页 dist。服务不执行 shell 拼接命令，FFmpeg 使用参数数组。项目不包含用户素材和模型密钥。端口可通过 PORT 环境变量调整。


## GitHub Pages
网页发布目录：docs/。在 Settings → Pages 选择 main 分支、/docs 目录。
