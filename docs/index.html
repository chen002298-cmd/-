开始你的第一版粗剪

1. 在“素材库”导入视频。补充人物、场景和动作标签；可填写分段入出点及已校对的台词。

2. 输入分镜，每行一镜，使用竖线分隔。也可导入 JSON。普通文本每行作为一镜处理。

3. 点击“解析并匹配”，检查备选镜头，设置源入出点、字幕、声音偏移及转场。

4. 回看后点击“导出 MP4”。下载影片、字幕或逐镜时间轴。

精剪模式提高编码质量；同步、口型、方言和混音仍需要人工复核。J/L 声音衔接使用 0.3 秒原声桥接，源素材需留有余量。

视觉识别：在启动服务前设置 VISION_API_KEY、VISION_BASE_URL、VISION_MODEL。点击“模型分析”会将六张采样帧发送到你配置的模型服务。
